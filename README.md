## DemoShop Automation Project

### Overview
This project demonstrates automated UI testing for the Demo Web Shop application using Java-based test automation.

### Project Goals
- Apply automated UI testing principles in practice
- Use Cucumber BDD to describe test scenarios in a readable format
- Build a clear and maintainable test automation architecture
- Practice Page Object Model and reusable helper utilities

### Technologies
- Java
- Selenium WebDriver
- Cucumber (BDD)
- JUnit 5
- Maven

### Project Structure
- Feature files describe user behavior and acceptance criteria
- Step Definitions map Gherkin steps to test code
- Page Objects encapsulate page logic and UI interactions

### Execution
Tests are executed via Maven using a Cucumber test runner.
